# Local game data

Game-data dumps are intentionally not stored in this repository.

To run the viewer with the default paths, place your locally generated files here:

- `SuzerainDataDumper.entity_data.json`
- `SuzerainDataDumper.conversations_Sordland.json`
- `SuzerainDataDumper.actor_names.json` (optional)

Optional runtime data can be placed under `data/runtime/`.

You can also start the application with `--data=/path/to/your/data` or choose the files from the application UI.
