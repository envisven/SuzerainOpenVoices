Its depth-bounded ancestry graph contained boundary copies that prevented some genuine fork/merge relationships from being recognized. Gain block 11 remains **one +1 write**, Conversation **226**, Dialogue **1007**, operation **0**. All **355 original route references** remain, alongside the additional slice's exact conditions, scripts, links and fork audit.

The normal Compact view now has **one logical requirement/choice region**, plus the retained family-summary annotation. It has **101 cells**, including meaningful alternative player-choice routes. More cells than the old incomplete 30-cell view is intentional: genuine route requirements are now related by AND/OR, rather than silently discarded or shown as unrelated segments. No “Separate source segment” bars appear in normal Compact mode. The direct **“A Morgna wes core!” — Alliance of Nations Assembly Meeting** choice remains.

## Algorithm

A shared reverse-link index serves target-specific breadth-first reachability. Nodes outside the write's reverse slice are excluded. Kahn ordering detects cycles; a reverse-topological pass computes postdominator intersections and memoized downstream conditions. Each node combines its local guard with the OR of surviving successors, then common requirements are factored. It does not enumerate complete root-to-write paths or Boolean assignments.

Boolean constant assignments are transferred backwards through downstream predicates before branch reduction. Other affected expressions retain an epoch-specific historical predicate. Thus the synthetic case `A → B=true; !A → B=false; merge → B → write` retains A. Unrelated writes can be preserved in provenance without preventing a proven equivalent target condition.

The first reduction establishes target-reachability equivalence. The display pass retains meaningful player-choice distinctions where routes have different one-sided restrictions; it removes guards only at the exact forks already proven exhaustive. Direct choices remain causal triggers. The existing Boolean coverage proof stays bounded; display expressions are capped at 2,500 syntax nodes. Large shared intermediate expressions stay as immutable expressions, with provenance attached when the display region is materialized.

Compact OFF retains the explicit previous source-DAG representation. Source mode remains independent. Logic markers stay inside actual Boolean regions and do not change cell geometry.
